# Movie Finder

Небольшой проект на Flask для поиска фильмов через TMDB.

## Запуск

1. Установите зависимости: `python3 -m pip install flask requests python-dotenv`
2. Создайте или проверьте файл `.env` рядом с `app.py`:
   ```text
   TMDB_API_KEY=ваш_ключ_TMDB
   ```
3. Запустите `python3 app.py` и откройте `http://127.0.0.1:5000`.

Файл `.env` исключён из Git. Не добавляйте реальные ключи в код или коммиты.

## Оценки

Оценка TMDB загружается из TMDB. Оценки IMDb, Letterboxd и Rotten Tomatoes загружаются по ID фильма из стороннего [What's on? API](https://github.com/pierrevano/whatson-api). Все четыре показаны рядом и ведут на страницы источников. У Rotten Tomatoes показаны оценка критиков и, если она есть, оценка зрителей. Данные внешнего API кешируются на шесть часов, поэтому могут немного отставать от сайтов. Если фильм отсутствует в API или тот недоступен, вместо числа остаётся ссылка на источник.

What's on? разрешает некоммерческое использование и ограничивает анонимные запросы до 50 в час и 200 в день. Это сторонний сервис, а не официальный API IMDb, Letterboxd или Rotten Tomatoes. Для IMDb и Rotten Tomatoes можно дополнительно указать собственный ключ [OMDb](https://www.omdbapi.com/apikey.aspx) в `.env` как `OMDB_API_KEY=ваш_ключ_OMDb`: он послужит запасным источником, если основная оценка отсутствует.

## Как устроены страницы

- `/` — поле поиска.
- `/search` — пять результатов TMDB.
- `/movie/<id>` — фильм, актёры, страна, язык, студии, оценки и рекомендации.
- `/movie/<id>/cast` — полный список актёров фильма.
- `/person/<id>` — все фильмы человека как актёра или режиссёра. Список идёт от новых фильмов к старым.
