# Movie Finder

Небольшой проект на Flask для поиска фильмов через TMDB.

## Запуск

1. Установите зависимости: `python3 -m pip install flask requests python-dotenv`
2. Создайте или проверьте файл `.env` рядом с `app.py`:
   ```text
   TMDB_API_KEY=ваш_ключ_TMDB
   ```
3. Запустите `python3 app.py` и откройте `http://127.0.0.1:5000`.

Файл `.env` исключён из Git. Не добавляйте реальные ключи в код или коммиты.

## Оценки

TMDB показывает свою среднюю оценку сразу. График Letterboxd раскрывается по нажатию через [официальное встраивание](https://embed.letterboxd.com/about/embed-our-ratings/); рядом есть прямая ссылка на фильм, если встраивание недоступно.

Для числовых оценок IMDb и Rotten Tomatoes нужен отдельный бесплатный ключ [OMDb](https://www.omdbapi.com/apikey.aspx). Если он у вас есть, добавьте в **свой** `.env` строку `OMDB_API_KEY=ваш_ключ_OMDb` и перезапустите Flask. Ключ никому не отправляйте. Без него карточки ведут на сайты с оценками.

## Как устроены страницы

- `/` — поле поиска.
- `/search` — пять результатов TMDB.
- `/movie/<id>` — фильм, актёры, страна, язык, студии, оценки и рекомендации.
- `/movie/<id>/cast` — полный список актёров фильма.
- `/person/<id>` — все фильмы человека как актёра или режиссёра. Список идёт от новых фильмов к старым.
